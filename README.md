# 动物小镇 · My Little Town

一个中英双语的儿童学习小镇：图书馆拼单词、书院读中文故事认字、面包店练乘除法和认钟表、杂货店算找零、健身房跟练、晚上写日记。

**在线玩：** https://qzhvicky.github.io/my-little-town/

- 用电脑上的 Chrome 或 Edge 打开效果最好。
- 第一次打开会问语言、孩子的名字和年龄。
- 右上角小锁是家长中心：第一次点会让你设一个 4 位数密码，可以看学习情况、调难度、设置每天游戏时间。
- 进度保存在当前浏览器里，换浏览器或清除浏览器数据会从头开始。
